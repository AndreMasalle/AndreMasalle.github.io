Semantic search for redundant project proposals

D3 final project · IEEE ICoAILO 2025

Problem

Final project proposals often overlap, causing duplication and slow manual review. This system automates semantic similarity detection to streamline proposal management.

Design constraints

  • Real-time operation: must respond quickly to support real-time use.
  • On-premise processing: student data must not leave the campus server.
  • High relevance: results must be as semantically close as possible to the query.
  • Lightweight model: small enough to deploy locally on campus infrastructure.

Approach

  • Sentence-BERT turns proposal text into dense vectors.
  • FAISS retrieves similar vectors with multithreaded execution.
  • Integrated into an existing Flask and Laravel platform so students can check similarity before submitting.

Results

  • Under 300 ms average response time, running on-premise.
  • Relevant matches across identical, paraphrased, and context-shifted proposals.
  • Validated with self-retrieval testing and t-SNE visualization.

Multiclass waste image classification

BDC 2026 Preliminary Round · Satria Data

Problem

Manual waste sorting is inefficient and error-prone. This classifier supports smarter recycling systems.

Approach

  • Cleaning: detected corrupt images, removed duplicates, filtered blurry images.
  • Preprocessing: background removal, dataset filtering, resizing.
  • EDA: class distribution, image size ratios, color intensity, t-SNE, Grad-CAM on a ResNet18 probe.
  • Per-batch augmentation: heavy on original images, light on background-removed ones, with a 20% chance of copy-paste onto synthetic backgrounds.
  • Trained ResNet50 (baseline), EfficientNet_B3, ConvNeXt_Tiny, and Swin_T, then ensembled them.

Results

  • 95% average macro F1 on the preliminary submission.
  • Modular stages for metadata extraction, cleaning, EDA, preprocessing, and training.

MBG tweet aspect classification

BDC 2026 Tel-U Internal Selection · Satria Data

Problem

Opinions on the Makan Bergizi Gratis policy are spread across thousands of Indonesian tweets. This model sorts them into 8 aspect categories to support policy analysis.

Approach

  • Fine-tuned IndoBERTweet for 8-class classification.
  • EDA on text length, emoji usage, and exclusive golden N-grams per aspect guided preprocessing, augmentation, and balancing.
  • Focal Loss with class weights, plus golden N-gram augmentation for minority classes.
  • Trained 5 models with 5-fold cross-validation, judged by balanced accuracy.

Results

  • Selected for the university delegation to BDC 2026.

Book recommendation system

Independent project · LLM, NLP

Problem

Keyword search and generic categories limit book discovery. This system understands the meaning of a query, simplifies genres, and matches emotional tone.

Approach

  • Cleaned 7,000+ raw books down to 5,197 records.
  • Semantic search with LangChain, OpenAI Embeddings, and ChromaDB, with ISBN tags mapping results back to metadata.
  • Zero-shot BART grouped 479 categories into 4.
  • RoBERTa scored 7 emotions per sentence, max-pooled per book.
  • Gradio dashboard with query, category, and emotion filters.

Results

  • 77.8% zero-shot accuracy on 600 held-out samples.
  • Emotion scores for all 5,197 books, deployed end to end from raw data to web UI.

Automobile data preprocessing pipeline

Data engineering project

Problem

The dataset was deliberately dirtied with missing values, duplicates, inconsistent text, and wrong data types. The goal was a modular, reproducible ETL pipeline.

Approach

  • ColumnTransformer and Pipeline separate numeric, categorical, and ordinal stages.
  • Custom transformers: CleanTeks and FrequencyEncoder.
  • Median and mode imputation; one-hot, ordinal, and frequency encoding; MinMaxScaler.

Results

  • 205 rows × 30 columns became 201 × 50 after cleaning.
  • Runs with a single command: python pipeline.py.
