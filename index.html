Semantic search for redundant project proposals

D3 final project · IEEE ICoAILO 2025

Proposals overlap and manual review is slow. The system flags similar proposals automatically and runs on campus servers, so student data stays on campus.

  • Search: Sentence-BERT embeddings with multithreaded FAISS retrieval.
  • Integration: Flask backend inside an existing Laravel platform.
  • Checks: self-retrieval testing and t-SNE.

Multiclass waste image classification

BDC 2026 preliminary round · Satria Data

Manual waste sorting is slow and error-prone. This classifier supports smarter recycling.

  • Cleaning: removed corrupt, duplicate, and blurry images.
  • Augmentation: per-batch, with copy-paste onto synthetic backgrounds.
  • Models: ResNet50, EfficientNet_B3, ConvNeXt_Tiny, and Swin_T as an ensemble.

MBG tweet aspect classification

BDC 2026 Tel-U internal selection

Opinions on the Makan Bergizi Gratis policy are spread across thousands of Indonesian tweets. This model sorts them into 8 aspects.

  • Model: fine-tuned IndoBERTweet.
  • Imbalance: Focal Loss, class weights, and golden N-gram augmentation.
  • Validation: 5-fold cross-validation on balanced accuracy.
  • IndoBERTweet
  • Focal Loss

Book recommendation system

Independent project

Keyword search limits book discovery. This system matches the meaning of a query, simplified genres, and emotional tone.

  • Search: LangChain, OpenAI Embeddings, and ChromaDB.
